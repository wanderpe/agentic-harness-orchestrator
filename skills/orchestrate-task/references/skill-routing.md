# On-demand techniques

Delivery-role skill selection is owned by [role catalog](role-catalog.json); use [role packets](roles.md) to load only the applicable subset.

| Other trigger | Load |
| --- | --- |
| ambiguous outcome or request for deeper work | [optional outcome lens](ambition-resource.md) |
| unexplained failure outside an active delivery role | [systematic-debugging](../../systematic-debugging/SKILL.md) |
| accepted multi-step requirements needing a plan | [writing-plans](../../writing-plans/SKILL.md) |
| success claim or completion handoff | [verification-before-completion](../../verification-before-completion/SKILL.md) |

Every technique preserves the selected role's permissions and the adopted workflow. A skill cannot authorize source changes during review, delegation, release, or scope expansion. Original upstream texts are passive provenance, not mandatory context. Sources and adaptations are in [third-party notices](../../../THIRD_PARTY_NOTICES.md); updates require review and a new plugin release.
